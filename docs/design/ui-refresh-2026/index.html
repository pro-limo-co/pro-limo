UI Refresh — three stances, side by side.

Testing one thesis: the web's editorial-luxury identity is its strongest asset, and ASTC mobile's real value is its interaction patterns and density, not its neutral aesthetic. Each surface below shows three variants that bracket that bet — from "change nothing visual" (A) to "go full app-mode" (C), with the hybrid (B) in the middle.

Mockups are hand-built HTML/CSS reusing the live design tokens from src/app/globals.css (champagne #C8A96A · Cormorant · Oswald · grain · the cinema-black palette). The AI-image path (/design-shotgun) was unavailable — no OpenAI key configured — so these are real, reflow-true HTML instead, which doubles as a head start on implementation.

Criterion 1
Brand fidelity
Does it still feel like pro-limo, or have we accidentally rebuilt ASTC?
Criterion 2
Density vs. air
Dispatch needs density; marketing needs breathing room; booking needs both.
Criterion 3
Mobile experience
B's snap-point sheet is the biggest mobile bet — does it earn the complexity?
Criterion 4
Implementation cost
A is ~free, B is medium, C is expensive (replaces product-surface chrome).
Criterion 5
Cross-surface coherence
If marketing and product diverge (C), does the brand still feel unified?
