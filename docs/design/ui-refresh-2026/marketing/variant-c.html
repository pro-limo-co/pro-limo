VARIANT C THESIS

Marketing stays fully editorial.

In Variant C the brand bifurcates: the public marketing pages keep the editorial-luxury identity untouched (identical to Variant A), while only the product surfaces — the booking wizard and the dispatch console — switch to the neutral app-mode UI. So this marketing mockup is intentionally the same as A. The contrast to evaluate for C lives in booking-flow/variant-c.html and dispatch-row/variant-c.html.

The question C forces: if a customer browses an editorial homepage and then drops into an app-mode booking flow, does the brand still feel like one coherent thing — or like two different products bolted together?
